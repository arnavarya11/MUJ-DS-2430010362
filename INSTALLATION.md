\# Installation and Setup Guide



\## Project Title

\*\*Stanford Cars Image Classification Using Deep Learning\*\*



\## 1. Project Overview

This project focuses on classifying car images using deep learning techniques and the Stanford Cars dataset.



\## 2. Prerequisites

Install the following before running the project:

\- Python 3.10 or later

\- Git

\- Jupyter Notebook or Google Colab

\- A CUDA-enabled GPU is recommended for faster training



\## 3. Clone the Repository

Open a terminal and run:



```bash

git clone https://github.com/arnavarya11/MUJ-DS-2430010362.git

cd MUJ-DS-2430010362

```



\## 4. Install Dependencies

Install the required Python libraries:



```bash

pip install -r requirements.txt

```



\## 5. Run the Notebook

Open `notebooks/2430010362.ipynb` in Jupyter Notebook or upload it to Google Colab.



In Google Colab:

1\. Upload or open the notebook.

2\. Select \*\*Runtime → Change runtime type\*\*.

3\. Select a GPU runtime if available.

4\. Run the notebook cells in order.



\## 6. Dataset

The project uses the Stanford Cars dataset, referenced as `mtb/StanfordCars` in the notebook. Ensure the dataset is accessible before running the training and evaluation cells.



\## 7. Hardware Recommendation

A GPU is recommended for training. Training time depends on the GPU, dataset processing, model architecture, and training configuration.



\## 8. Evaluation

Run the notebook's evaluation cells to obtain the model's performance metrics. Record the actual results after completing evaluation; no accuracy value is assumed in this guide.
